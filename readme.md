# 🔐 A7 Login Admin

Este plugin personaliza a tela de login do WordPress, substituindo a aparência padrão por uma tela moderna e personalizada com a identidade visual da **A7 Sites**. Ideal para quem deseja um login mais profissional e integrado à marca.

---

## ✨ Características

- 🖼️ Tela de login personalizada com identidade visual da **A7 Sites**  
- 🔒 Layout moderno, responsivo e elegante  
- 🧭 Logotipo personalizado, cores e mensagens institucionais  
- 💡 Fácil ativação, sem necessidade de configurações adicionais  
- 🔧 Compatível com a maioria dos temas e plugins WordPress  

---

## 📥 Instalação

1. Faça o upload do plugin para a pasta `/wp-content/plugins/a7-login-admin/`.  
2. Ative o plugin através do menu **Plugins** no painel do WordPress.  
3. A tela de login será automaticamente substituída pela versão personalizada da **A7 Sites**.
